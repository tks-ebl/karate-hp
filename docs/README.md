# 矢頭派糸東流修交会 修義舘 サイト

GitHub Pages で公開する静的サイトです。

## フォルダ構成

- `index.html`: トップページ
- `pages/`: 下層ページ
- `assets/css/styles.css`: 共通スタイル
- `assets/images/`: 画像素材
- `docs/`: サイト構成メモ、相関図、運用資料

## 主なページ

- `pages/about.html`: 道場説明
- `pages/practice.html`: 稽古紹介
- `pages/locations.html`: 稽古場所一覧
- `pages/fees.html`: 月謝・入会案内
- `pages/faq.html`: Q&A
- `pages/news.html`: お知らせ
